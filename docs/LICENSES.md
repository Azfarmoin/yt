# Licensing and zero-cost audit
Run `python -m ivs audit` for the live version (dependency table + environment checks). Summary:

| Component | License / terms | Cost |
|---|---|---|
| Python, Pillow, PyYAML, requests, Flask, pytest | permissive OSS | free |
| FFmpeg | LGPL/GPL depending on build | free |
| Amiri, Noto Sans, Noto Nastaliq Urdu, Noto Naskh Arabic | SIL OFL 1.1 (license files in `assets/fonts`) | free |
| Quran Arabic text (King Fahd Complex Uthmani Hafs v13) via fawazahmed0/quran-api | source terms: qurancomplex.gov.sa — do not alter text; attribute | free |
| Urdu (Fateh Muhammad Jalandhry), English (Abdullah Yusuf Ali), Arabic cross-check — Tanzil data | Tanzil terms: verbatim, attribute, no modification | free |
| Hadith text via fawazahmed0/hadith-api | open data mirror of published texts | free |
| Recitation (EveryAyah, default Alafasy) | fetched by you; verify terms for monetized channels | free |
| YouTube Data API v3 | Google API ToS; free quota | free within quota |

Zero-cost enforcement: `zero_cost_mode` cannot be switched off, and config containing a known paid-provider name is refused at startup.
Videos use only generated geometric art, so there are no stock-footage licenses to track; any external asset must be recorded in `assets_used` with a license or QC fails.
